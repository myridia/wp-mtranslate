# AGENTS.md — wp-mtranslate

## What this is
A WordPress plugin for Myridia-based translation of WordPress content.

## Stack
- PHP (WordPress plugin)
- WordPress

## Build
No build step; plugin files are placed directly in WordPress.

## Run
Install as a WordPress plugin in `wp-content/plugins/` and activate via WordPress admin.

## Structure
- `*.php` — plugin files

## Conventions
- No comments in code unless asked.
- Follow WordPress coding standards.
- Verify: `php -l <file>.php`
